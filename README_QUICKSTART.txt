DESKTOP / INSTRUMENT 01 — ZERO-INSTALL VERSION

This edition is designed for desktop monitors and uses a responsive 16:9 artboard.

LOCAL:
  Open index.html in Chrome or Edge.
  The main image can be clicked to upload a PNG/JPEG/WebP/GIF.
  Mouse over the instrument to reveal controls.
  Space = pause; I = image; A = audio; G = generate original music; M = mute.

GITHUB PAGES:
  Upload ALL files from this directory to the ROOT of a GitHub repository.
  Settings > Pages > Deploy from a branch > main / (root).
  The page needs index.html, standalone.js, style.css, and default-character.jpg at the same level.

No backend or paid APIs. The bundled character crop comes from the user-provided
reference screenshot and should be replaced before publishing if rights are unclear.
