# PIXEL INSTRUMENT / 데스크탑 최종본

원본 이미지의 연회색 배경·핑크 포인트·얇은 격자와 계기판 스타일을 유지하면서 1920×1080 데스크탑에 맞춘 인터랙티브 음악 시각화 웹사이트입니다.

## 바로 실행

`standalone/index.html`을 Chrome 또는 Edge에서 열어 사용합니다. GitHub Pages에는 `standalone/` 폴더 안의 파일을 저장소 최상단에 업로드한 다음 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.

## 조작

- 캐릭터 이미지를 클릭하면 사진 또는 GIF를 변경할 수 있습니다.
- 이미지의 픽셀 데이터를 16×12 공간 시드로 변환하고 8개 동적 신호로 모든 계기판에 반영합니다.
- GIF를 업로드하면 각 프레임에서 실제 팔레트를 추출해 강조색·배경 톤을 부드럽게 변경하고, 프레임 차이·영역별 변화·프레임 타이밍도 계기판 애니메이션에 반영합니다.
- `GENERATE`로 오리지널 전자음을 재생하고, `AUDIO`로 로컬 음악 파일을 분석할 수 있습니다.
- 키보드: `I` 이미지, `A` 오디오, `G` 생성 음악, `D` 무음 시각화, `Space` 일시정지, `M` 음소거, `R` 처음부터.
- 마우스를 화면 위로 이동하면 간소한 메뉴가 보입니다.

## 검증과 제약

독립 실행형 버전은 실제 Chromium Canvas·WebAudio·파일 업로드 테스트에서 이미지 시드 변경, GIF 6프레임 디코딩·프레임 반응·정지/재개, 데스크탑/모바일 레이아웃, 사운드 모드, 반복 교체를 확인했습니다. React 버전의 npm 프로덕션 빌드는 해당 테스트 환경의 패키지 설치 제약으로 검증하지 못했습니다. 매우 큰 GIF는 안전 제한을 초과하면 원본이 표시되어도 프레임 동기화는 중단될 수 있습니다.

기본 애니메이션 캐릭터 사진은 사용자가 제공한 참조 이미지의 일부입니다. 공개 배포 전 해당 이미지의 사용 권한을 확인하고 필요한 경우 본인 소유의 그림으로 교체하세요.

## 최종 품질 개선 및 검증 (2026-11-19)

- 4프레임 빨강/파랑/초록 테스트 GIF를 Chromium에 업로드해 프레임 팔레트에 따라 계기판 강조색이 변하는 것과 GIF 캔버스 픽셀을 확인했습니다.
- GIF 자체 재생 시계를 음악 재생시계 전환과 분리했습니다. 오디오 파일이 루프·교체되어도 GIF가 멈추지 않으며, 일시정지는 둘 다 함께 적용합니다.
- 매 프레임 생성되는 RGB 문자열을 색상 캐시에 무한히 저장하지 않도록 변경했습니다.
- 작은 고채도 영역으로 인해 전체 팔레트가 자주 뒤집히지 않도록 지배적인 색상에 가중치를 주었습니다.
- 렌더러의 하드코딩 핑크색 일부를 테마 색상으로 바꾸고 툴바·포커스 색상도 이미지 색에 맞춥니다.
- GIF 직접 디코딩이 불가능한 경우 네이티브 GIF 샘플러도 프레임별 팔레트 추출을 시도합니다. 네이티브 샘플링 정확도는 브라우저에 따라 제한될 수 있습니다.
- PNG/JPEG/WebP는 업로드 시 테마를 변경하며, 정적인 이미지에는 매 프레임 색상 변화를 만들지 않습니다.
- 안전 제한: 이미지 24MB, 이미지 원본 4천만 픽셀, GIF 320프레임/9천2백만 패치 픽셀 제한. 초과 GIF는 기본 재생에 폴백합니다.
- 오프라인 검증: `node scripts/smoke-standalone.cjs` 및 `node scripts/test-pixel-engine.cjs` (후자는 TypeScript 설치 필요).
- Chromium 통합 QA: `python scripts/test-live-theme-browser.py` (`pip install playwright` 및 Chromium 필요).
- 이 실행 환경에서 npm 레지스트리에 접근할 수 없어 React/Vite 전체 프로덕션 빌드는 미검증입니다. **배포는 별도 설치가 필요 없는 standalone 폴더를 권장합니다.**
